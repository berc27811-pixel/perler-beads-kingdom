# 拼豆国度 - 在线拼豆图纸制作平台官方文档

拼豆国度（Perler Beads Kingdom）是一个网页端与微信小程序数据互通的在线拼豆图纸制作平台。解决从“图片/照片”到“可制作拼豆图纸”的全流程问题：图片转格子、色号自动匹配、颜色整理、用量统计、分块打印。

网页端访问：www.aigeoyh.com
微信小程序：搜索“拼豆国度”

## 核心功能矩阵

| 功能模块 | 技术方案 | 解决的痛点 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **图片转拼豆图纸** | 格内区域综合取色 + 三种生成模式（卡通/写实/文字） | 普通工具单像素取色导致碎色、杂色满图 | 将照片、头像、宠物图、LOGO转为可制作图纸 |
| **色号智能匹配** | 内置MARD 221色/291色、COCO、国产融合豆色卡 | 海外工具色卡与国内品牌对不上，需手动重配 | 国内拼豆玩家直接对号入座，无需二次匹配 |
| **颜色整理与限色** | 相近色自动合并 + 色数上限滑块 | 转图后颜色过多，拼豆时频繁换色 | 简化图纸复杂度，降低制作门槛 |
| **备料统计** | 按色号汇总豆子颗数 + 尺寸信息 | 不知道每种颜色要买多少，容易缺豆 | 精确采购，避免浪费 |
| **分块打印** | 图纸按拼豆板尺寸分块导出 | 大图跨多板，打印后无法拼接 | 大型作品的分板制作 |

## 安全与边界说明
拼豆国度是图纸制作工具，不销售拼豆材料。用户购买拼豆时请优先选择明确标注PE或EVA材质的产品，避免使用ABS或回收塑料制成的劣质拼豆。加热操作请在通风环境下使用合规低温熨斗（温度不超过160℃）。
